# 🐾 TalkieFriends (토키프렌즈) v5 — 블루이·빙고 나노바나나 영어놀이 앱

6~7세 한국 아이가 혼자서도 캐릭터와 장소를 고르고, **진짜 친구처럼 영어로 자유 토킹·역할놀이**를 주고받는 동화책 영어 앱입니다.  
**다른 컴퓨터·태블릿에서도 내 데이터를 그대로 이어 쓰는 클라우드 동기화**, **앱처럼 설치(PWA)**, **제미나이 라이브(Gemini Live) 실시간 양방향 음성 대화**까지 모두 포함되어 있습니다.

---

## ✨ 핵심 기능 (v5)

### 1. 💬 자유 토킹 (롤플레이 없음) + 🎭 5개 영역별 즉흥 역할극
- **🌈 자유 토킹 모드 (`free_talk`)**: 정해진 역할극 대본 없이 공룡·간식·유치원·가족·좋아하는 색깔·감정 등 아이가 꺼낸 주제로 꼬리 질문을 이어가며 진짜 수다를 나눕니다.
- **🎭 5개 영역별 즉흥 역할극**: 라면 카페 · 자카란다 뒷마당 소풍(달력·요일) · 파스텔 동물병원 · 노을 무지개 놀이터(인성·매너) · 파닉스 보물 마켓 — 아이가 엉뚱한 상상을 말해도 대본만 기계적으로 읽지 않고 맥락을 받아줍니다.
- **5가지 성향별 반응 차별화**: 블루이(장난꾸러기) · 빙고(다정다정) · 러스티(씩씩히어로) · 코코(조용차분) · 마일로(호기심 탐험가) 성향에 따라 감탄사·교정·4.5초 힌트·애니메이션이 다르게 작동합니다.

### 2. ⚡ 진짜 제미나이 라이브 (Gemini Live) 실시간 양방향 음성
- WebSocket(`BidiGenerateContent`)으로 **16kHz PCM 마이크 입력 → 24kHz 원어민 네이티브 음성 출력**을 버튼 없이 핸즈프리로 주고받습니다.
- **오디오 파형(RMS) 기반 실시간 립싱크**: 캐릭터 목소리 볼륨에 맞춰 나노바나나 리깅 캐릭터의 입·머리·팔·꼬리가 자연스럽게 움직입니다.
- **6~7세 맞춤 VAD 설정**: 아이가 단어를 떠올리느라 잠깐 멈칫해도 끊기지 않도록 `silenceDurationMs: 1600`, `prefixPaddingMs: 300`을 적용하고, 4.5초 침묵 시 자동으로 다정한 힌트를 먼저 건넵니다.
- **중간 끼어들기(Barge-in)** 지원 + 실시간 음성 자막을 분석해 커리큘럼 별·취약 표현 복습장·부모님 리포트에 자동 반영합니다.
- *API 키 없이도* 내장 토픽 인식 자유대화·역할극 엔진 + 표준 미국식 영어(`en-US`) 음성으로 즉시 작동합니다.

### 3. ☁️ 다른 컴퓨터에서도 내 것으로 이어쓰기 (크로스 기기 동기화)
- **가족 동기화 코드 (`🔒 엄마·아빠 → ☁️ 기기연동·앱설치`)**: 예) `BLUEY-2026` + 선택 PIN 번호만 입력하면 집 PC·노트북·태블릿 어디서나 커스텀 캐릭터 사진, 취약 표현 복습장, 지난 수업 리포트 기록이 자동 동기화됩니다.
- **오프라인 백업 파일 (`.tfbackup.json`)**: 서버 없이도 파일 1개로 카톡·USB를 통해 다른 컴퓨터에 100% 복원할 수 있습니다.

### 4. 📲 앱처럼 다운로드 · 설치 (PWA)
- `manifest.json` + `sw.js`(Service Worker) + 블루이 전용 앱 아이콘(`192px`, `512px`, `apple-touch-icon`) 완비.
- PC(크롬/엣지)·안드로이드: 앱 안의 **`📲 앱으로 설치하기`** 버튼 1클릭으로 바탕화면 독립 앱처럼 설치.
- 아이패드/아이폰(Safari): 하단 **공유(⬆️) → 홈 화면에 추가**.

### 5. 🎨 나노바나나 분리 배경 + 6파츠 관절 리깅 + 내 사진 캐릭터(BYOC)
- 캐릭터가 없는 순수 수채화 배경 5종과 6파츠 투명 관절 스프라이트(`head_idle`, `head_talk`, `body`, `arm_l`, `arm_r`, `tail`)가 분리되어 있습니다.
- 아이가 좋아하는 캐릭터 사진 1장만 올려도 흰 배경을 자동 제거하고 머리·몸통이 움직이는 캐릭터로 만들어 줍니다.

### 6. 원어민 선생님 핵심 규칙 `[0]`~`[5]` 철저 준수
- **`[0]` 모드 분리**: Live 음성 대화 중 그림 생성 완전 차단; Pre-Live `🎨 그림방`에서만 `"그림 그려줘"` 시 1장씩 생성.
- **`[1]`~`[4]`**: 표준 미국식 영어(`en-US`), 어눌한 발음 문맥 이해, 멈칫함 보호, 4.5초 침묵 선제 힌트, 부드러운 교정 & 한국어→영어 전환, 취약 표현 다회차 복습.
- **`[5]` 무음 부모님 리포트**: Live 종료 또는 `.` / `끝` / `요약해줘` 입력 시 즉시 모든 음성/라이브 연결을 끊고 5항목 텍스트 리포트만 출력합니다.

## 🚀 내 서버로 실행 & 클라우드 배포 (다른 컴퓨터 어디서나 접속)

### 로컬 실행 (Node.js 20+ / 외부 패키지 설치 불필요!)
```bash
npm start
# 또는 Gemini Live 서버 공용 키까지 함께 실행:
GEMINI_API_KEY="AIza..." npm start
```
기본 포트는 `8765`입니다 (`PORT=3000 npm start`로 변경 가능).

### Render / Railway / Fly.io 무료·저가 클라우드 배포 (1클릭)
1. 이 폴더를 GitHub 저장소에 올립니다.
2. **Render**에서 `New → Blueprint`로 `render.yaml`을 선택하거나, `Dockerfile`로 배포합니다.
3. (선택) Render 환경변수에 `GEMINI_API_KEY`를 등록해 두면 브라우저에 API 키를 노출하지 않고 서버가 안전하게 일회용 **Ephemeral Token**(`/api/gemini-live-token`)을 발급해 어느 컴퓨터에서든 바로 Gemini Live 실시간 음성을 사용할 수 있습니다!
4. 배포된 HTTPS 주소에 접속해 **`📲 앱으로 설치하기`** + **가족 코드 입력**을 하면, 집·친정·여행지 어떤 컴퓨터와 태블릿에서도 내 아이의 영어놀이 앱이 그대로 이어집니다.
